# 사용·운영 인계 · v1.2

앱을 열면 전체 범위가 포함되어 있다. 과목을 선택하고 바로 시작한다. 범위를 줄이려면 ‘범위 조정’에서 필요한 항목만 해제한다. 저장 버튼 없이 즉시 저장되고 다음 묶음에 반영된다. 진행 중인 묶음은 ‘이어서 하기’로 이어간다.

처음 보는 자료는 읽기→가리기→복원→원문 확인→자기평가 순서다. 표와 도식의 가림은 원래 자리에서 공개된다. 복잡한 그림은 문장과 함께 표시하며, 회상 중에는 그림을 숨겨 답이 드러나지 않게 한다. 원문 대조 단계에서 다시 나타나고 화면 안에서 확대한다. 자료 목록에서 제목이나 본문을 검색해 바로 학습할 수도 있다. 문항·해설 개념도 기본 포함이다.

학습 자료와 공개 그림은 자동으로 저장한다. 별도 다운로드 절차가 없다. 홈 하단의 ‘오프라인 준비됨’이 표시되면 연결을 끊고 다시 열어도 학습할 수 있다. 원본 교재 사진은 참고용으로 열 때 저장하므로 처음 여는 원본 사진은 연결이 필요하다. 사진 저장 실패가 문장·표 학습을 막지 않는다.

이전 사진 학습 기록은 보존한다. 미완료 큐의 사진 자료는 연결된 문장·표·도식으로 전환하며, 이미 평가한 기록은 바꾸지 않는다. v1.1에서 처음 전환할 때 범위가 한 번 전체로 지정되고 이후 해제한 선택은 유지한다. 홈에서 대기 중일 때는 새 자료가 준비되면 자동 갱신한다. 학습 중에는 진행 상태를 유지하고 묶음을 마친 뒤 설정에서 새 버전을 적용한다. 브라우저 데이터를 삭제하지 않는다.

기록은 설정에서 내보내고 가져올 수 있다. 백업은 ID로 병합하며 두 번 가져와도 중복 집계하지 않는다. 저장 오류나 다른 탭 충돌이 보이면 진행하기 전에 재시도 또는 최신 상태 불러오기를 사용한다. 기기를 옮기기 전에는 백업한다.

비공개 자료 묶음의 public/content와 content/private를 복원한 뒤 README의 빌드·검사·prebuilt 배포 절차를 따른다. 교재 자료와 인증 정보는 공개 Git에 올리지 않는다. 기존 Vercel 보호 설정을 유지한다. 실제 S26 Ultra·TalkBack·물리 키보드 성능 검증은 별도다.
