# 사용·운영 인계

홈에서 과목과 범위를 고르고 시작한다. 처음 접한 원문은 읽기부터, 본 원문은 가린 상태부터 시작한다. 빠른 복원은 머릿속으로 답한 뒤 원문 확인, 직접 복원은 각 칸에 입력한 뒤 대조한다. ‘전부’는 사용자의 자기평가이며 기계 일치나 독립 복원 여부와 별도다. 원본·힌트를 먼저 열면 도움 사용을 기록한다.

자료 화면은 학습 단위, 소단원 팩, 전체 페이지 상태를 제공한다. 자료 유형에서 문항·해설 개념을 선택하거나 검색하고 바로 학습할 수 있다. 원본 페이지 아래에는 해당 제시문·해설·관련 본문이 연결된다. 표는 표 내부에서 가로 이동하며, 그림 확대는 가림을 유지한다. 원본 버튼은 전체 페이지와 해당 원문 영역을 표시한다. 공식 보완 설명에는 기관 이름과 외부 원문 링크가 있다. 링크 접속만 인터넷이 필요하다.

전체 페이지 이미지에서 ‘가릴 문단·표·그림 선택’을 누른다. 드래그하거나 네 방향 범위를 조절해 영역을 정하고 ‘선택 영역으로 학습’을 누른다. 크게 읽기→영역 전체 가림→원문 대조→자기평가 순서다. 영역 학습은 빠른 복원이고 좌표도 시도 기록과 백업에 남는다. 기본 용어 가림으로 돌아갈 수도 있다.

오프라인 사용 전 원하는 소단원 팩의 다운로드를 완료한다. 시작할 때 필요한 팩도 준비한다. 브라우저에서 설치 메뉴 또는 홈 화면 추가로 설치할 수 있다. 설치 UI는 브라우저·기기에 따라 다르다. PWA 설치와 독립 실행은 S26 Ultra 실기기에서 확인하지 못했다.

기록은 이 브라우저에만 저장된다. 설정의 기록 내보내기로 JSON을 보관하고 새 브라우저에서 백업 가져오기로 병합한다. 팩은 다시 받는다. 지속 저장 요청이 거절되거나 브라우저가 캐시를 회수할 수 있으므로 백업을 별도로 유지한다. 저장 실패 배너가 보이면 저장 공간을 확보하고 다시 저장한다. 다른 탭 배너는 최신 기록을 불러온 후 계속한다.

## 자료 교정과 배포

원본 PDF의 해시를 먼저 확인한다. tools/render.py → OCR → curated.py·expansion.py 대조 검수 및 regions.json 좌표 검수 → tools/ingest.py → npm run build 순서다. 제공한 비공개 묶음의 curated.py, expansion.py, regions.json, official.json, OCR·회전 후 OCR·corrections·manifest·좌표 증명를 유지한다. 공개 Git에는 자료와 인증 파일을 올리지 않는다. 기존 단위는 순서를 유지한다. 교정 시 stable ID/revision을 명시적으로 관리하고 version을 올린다. 좌표는 회전 후 페이지와 크롭 내부 좌표를 구분한다. 새 팩은 모든 asset checksum과 출처 검사를 통과해야 한다.

현재 별도의 관리자 UI는 없다. 검수 입력을 코드로 편집하는 운영 방식이다. 원본 전체를 자동 OCR한 결과를 그대로 배포해서는 안 된다. 135쪽은 모두 원본 열람 및 개념 연결이 있다. 대표 128쪽은 전체 이미지에서 임의 영역을 학습한다. 중복 6쪽은 대표 쪽 학습으로 연결한다. 사회 45쪽은 44쪽과 같은 책 82쪽, 사회 79쪽은 판독 가능한 해설 3개를 반영했으며 잘린 영역은 전사하지 않았다. 완전한 교재 전사나 누락된 교재 페이지의 복원을 주장하지 않는다.

배포는 README의 로컬 prebuilt 절차를 사용한다. Vercel 보호가 설정되어 있어 계정 인증 후 접속한다. 검증을 위해 보호를 해제하지 않는다. 기존 앱 사용자는 묶음을 마친 뒤 앱을 다시 열고 설정의 ‘업데이트 확인’ 또는 ‘새 버전 적용’을 누른다. 이전 앱에서는 새 worker가 준비된 뒤 설정을 다시 열면 ‘새 버전 적용’이 나타난다. 적용 후 자료 버전 v1.1.0을 확인하고 선택한 소단원 팩을 갱신한다. 기록을 지우지 않는다. 첫 배포 및 이후 갱신 전 백업을 권장한다. 장기 운영에서 구버전 팩 캐시를 자동 정리하는 정책과 10만 건 이상 기록 성능은 추가 검증 대상이다.

## 확인이 남은 환경

S26 Ultra 실제 화면 확대 설정, Samsung Keyboard/Gboard 실제 한글 조합, 키보드 표시 상태, PWA 독립 실행·설치, 60/120Hz, 절전·발열, 20–30분 지속 사용은 이 Windows 환경에서 검증하지 못했다. Playwright 모바일 viewport와 합성 IME 이벤트 결과를 실기기 검증으로 대신 표기하지 않았다.
