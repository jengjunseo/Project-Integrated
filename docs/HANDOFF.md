# 사용·운영 인계

홈에서 과목과 범위를 고르고 시작한다. 처음 접한 원문은 읽기부터, 본 원문은 가린 상태부터 시작한다. 빠른 복원은 머릿속으로 답한 뒤 원문 확인, 직접 복원은 각 칸에 입력한 뒤 대조한다. ‘전부’는 사용자의 자기평가이며 기계 일치나 독립 복원 여부와 별도다. 원본·힌트를 먼저 열면 도움 사용을 기록한다.

자료 화면은 학습 단위, 소단원 팩, 전체 페이지 상태를 제공한다. 표는 표 내부에서 가로 이동하며, 그림 확대는 가림을 유지한다. 원본 버튼은 전체 페이지와 해당 원문 영역을 표시한다. 공식 보완 설명에는 기관 이름과 외부 원문 링크가 있다. 링크 접속만 인터넷이 필요하다.

오프라인 사용 전 원하는 소단원 팩의 다운로드를 완료한다. 시작할 때 필요한 팩도 준비한다. 브라우저에서 설치 메뉴 또는 홈 화면 추가로 설치할 수 있다. 설치 UI는 브라우저·기기에 따라 다르다. PWA 설치와 독립 실행은 S26 Ultra 실기기에서 확인하지 못했다.

기록은 이 브라우저에만 저장된다. 설정의 기록 내보내기로 JSON을 보관하고 새 브라우저에서 백업 가져오기로 병합한다. 팩은 다시 받는다. 지속 저장 요청이 거절되거나 브라우저가 캐시를 회수할 수 있으므로 백업을 별도로 유지한다. 저장 실패 배너가 보이면 저장 공간을 확보하고 다시 저장한다. 다른 탭 배너는 최신 기록을 불러온 후 계속한다.

## 자료 교정과 배포

원본 PDF의 해시를 먼저 확인한다. tools/render.py → OCR → curated.py 대조 검수 → tools/ingest.py → npm run build 순서다. 제공한 비공개 묶음의 curated.py, official.json, OCR·corrections·manifest를 유지한다. 공개 Git에는 자료와 인증 파일을 올리지 않는다. 기존 단위는 순서를 유지한다. 교정 시 stable ID/revision을 명시적으로 관리하고 version을 올린다. 좌표는 회전 후 페이지와 크롭 내부 좌표를 구분한다. 새 팩은 모든 asset checksum과 출처 검사를 통과해야 한다.

현재 별도의 관리자 UI는 없다. 검수 입력을 코드로 편집하는 운영 방식이다. 원본 전체를 자동 OCR한 결과를 그대로 배포해서는 안 된다. 135쪽은 모두 원본 열람이 가능하며 학습 원문은 선택 구간 검수다. 사회 45·79쪽의 심한 왜곡/잘림과 중복 사진은 감사 목록에 남겼다. 완전한 교재 전사나 누락된 교재 페이지의 복원을 주장하지 않는다.

배포는 README의 로컬 prebuilt 절차를 사용한다. Vercel 보호가 설정되어 있어 계정 인증 후 접속한다. 검증을 위해 보호를 해제하지 않는다. 새 버전이 있으면 묶음을 마치고 설정에서 새 버전 적용을 누른다. 첫 배포 및 이후 갱신 전 백업을 권장한다. 장기 운영에서 구버전 팩 캐시를 자동 정리하는 정책과 10만 건 이상 기록 성능은 추가 검증 대상이다.

## 확인이 남은 환경

S26 Ultra 실제 화면 확대 설정, Samsung Keyboard/Gboard 실제 한글 조합, 키보드 표시 상태, PWA 독립 실행·설치, 60/120Hz, 절전·발열, 20–30분 지속 사용은 이 Windows 환경에서 검증하지 못했다. Playwright 모바일 viewport와 합성 IME 이벤트 결과를 실기기 검증으로 대신 표기하지 않았다.
