## 문항과 해설

문항·해설 개념 123개가 기본 출제에 포함된다. 본문·문항·해설·핵심 자료를 sourceRole로 구분하고 자료실 유형 필터와 직접 학습을 제공한다. 분류된 모든 문항 쪽 59개에는 검수 제시문·해설 또는 관련 본문 개념이 연결된다. 오답 선지를 참인 사실로 일괄 변환하지 않았다. 질문 이미지에서는 정오 판단 맥락을 안내한다.

사회: 아리스토텔레스·에피쿠로스, 레오폴드·베이컨, 기후 자료, 이슬람교와 문화 융합, 자극 전파, 인권 발달, 외부 불경제·공공재·정부 실패, 헌법의 경제 질서, 청소년 노동권, 롤스·노직, 사회 보험·공공 부조, 뉴딜·신자유주의, 금융 자산, 갈퉁·칸트, 인구 구조·다문화 등을 반영했다.

## 원문 전체의 학습

원본 135쪽 전체를 보존한다. 대표 128쪽은 기본 용어 가림 외에 원하는 문단·표·그림을 직접 선택하여 크게 읽고 통째로 가리고 대조할 수 있다. 영역의 좌표도 저장·평가·undo·백업으로 보존하며, 선택 영역 학습은 문자 자동 채점 없이 빠른 복원·자기평가를 사용한다. 따라서 발췌하지 않은 부분도 원본 그대로 회상 학습에 쓸 수 있다.

중복·부분 촬영 6쪽은 대표 쪽으로 연결한다: 사회 38·39→37, 45→44; 과학 28→27, 40→39, 49→48. 사회 79쪽은 읽을 수 있는 해설 3개를 반영했고 잘린 내용은 전사하지 않았다. 사회 77쪽은 본문 연속 페이지로 분류를 수정했다. 전체 문장의 네이티브 텍스트 전사 완료와 원본 전체 이미지 보존은 구분한다.

## 표·그래프와 좌표

통계 그래프 3개는 교재 수록 외국인 주민 국적 비율·2006–2022년 주민 수 추이·동일 유용 에너지 조건의 공급량이다. 단위·기준 시점을 표시하며 막대의 기준 폭을 동일하게 유지한다. 반복 용어는 같은 번호로 여러 위치를 가린다. WinRT OCR의 기울어진 좌표를 원본 이미지 좌표로 변환하고 13장의 페이지별 좌표 증명 이미지를 대조했다. 사회 74–81쪽은 회전 후 OCR을 다시 수행했다.

## 검증과 한계

초기 171개 자료의 ID·revision·원문·target 해시가 유지되는 것을 검사했다. 자료 무결성·문항 연결 누락·가림 좌표·정답 구간·그래프 수치를 빌드에서 검증한다. 도메인 및 실제 브라우저 검증 결과는 QA_REPORT.md와 qa-results.json, 배포 응답 검증은 DEPLOYMENT.md를 따른다.

전체 전사 검수, 누락된 교재 페이지의 복원, S26 Ultra 실기기·실제 키보드·120Hz·장시간 사용은 완료했다고 주장하지 않는다. 원본 사진의 잘린 내용은 제공 이미지나 외부의 확정 근거 없이 생성하지 않았다.
