# v1.2 · 바로 시작하는 학습

사용자는 전체 범위를 기본으로 하고 필요할 때만 해제하며, 개별 다운로드와 표·그림 사진에 의존하는 흐름을 없애도록 요청했다. 첨부 개발 명세보다 최신 사용자 요구를 우선했다.

- 처음부터 사회 10·과학 12개 소단원을 모두 포함한다. 별도 저장 없이 제외 항목을 바로 반영한다. 기존 설정은 버전 전환 시 한 번 전체로 바꾸고 이후 제외 선택을 유지한다.
- 시작·재개·개별 자료 학습에서 소단원 다운로드 대기를 제거했다. 학습 자료와 복잡한 보완 그림은 worker가 자동 저장한다. 원본 135쪽은 열 때 검증·저장한다.
- 339개 기본 학습 자료에 문항·해설 개념 123개가 포함된다. 기존 321개에 네이티브 자료 13개와 공식 시각 보완 5개를 더했다. 전체 470개 보존 레코드 중 과거 사진 학습 131개는 호환·원본 참고용이며 새 개념 수로 세지 않는다.
- 표 54개, 그래프 4개, 순서도 10개, 관계도 3개, 영양 단계 도형 1개를 읽을 수 있는 웹 요소로 제공한다. 에너지 효율 식도 문자다. 표·도식은 답을 원래 자리에서 가리고 공개한다. 반복된 답도 빠짐없이 가린다.
- 단사슬·복사슬·규산염 사면체·에너지 수지·동식물 세포 그림의 출처와 이용 조건을 표시한다. 별도 파일 다운로드나 외부 사이트 이동 없이 학습 화면에서 확인·확대한다.
- 이전 시도·복습·백업을 보존하고, 미완료 사진 큐는 연결된 네이티브 자료로 전환한다. 전체 문장의 전사 완료를 주장하지 않는다. 사회 79쪽의 잘린 영역은 계속 미전사 상태다.

검증 결과는 QA_REPORT.md, 실제 배포 증거는 DEPLOYMENT.md, 그림 이용 근거는 VISUAL_SOURCES.md에 연결한다.
